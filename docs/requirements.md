# 俄语背词 APP - 需求文档

## 项目定位
面向俄罗斯留学场景的个人俄语单词学习PWA，专注高频词变格/变位实用记忆。

## 用户画像
- 已有俄语基础（B1-B2水平）
- 需要在留学日常交流中快速运用
- 不需要发音功能
- 要求极简无干扰

## 核心功能

### 1. 词书体系
- 词书命名格式：`树人常用俄语X词（N）`（N为序号，递增）
- 每本词书为独立学习单元
- 已收录词汇自动去重，避免跨书重复
- 支持自定义每日学习量

### 2. 学习流程（三按钮模型）
- 卡片展示：单词 + 重音 + 中文释义 + 词性标签
- 点击单词 → 浮层展示完整变格/变位表
- 三个操作按钮：
  - **认识** ✅ → 标记掌握，30天后偶尔抽查
  - **模糊** 🤔 → 3天后复习
  - **不认识** ❌ → 1天后立即复习
- 随机顺序出词
- 每日新词配额控制

### 3. 复习系统
- 基于艾宾浩斯遗忘曲线
- 被标记"不认识/模糊"的词自动进入复习队列
- 复习间隔根据答题反馈动态调整
- 认识→延长间隔 / 模糊→保持 / 忘记→缩短

### 4. 我的
- 学习统计（已学/掌握/待复习）
- 每日新词目标设置
- 数据导出/导入备份

## 非功能需求
- 纯离线使用（PWA）
- iPhone全尺寸适配
- 低饱和浅灰+冷蓝配色
- 零成本，无服务器
